# القنصل — النسخة الرئيسية المحسنة

هذه الحزمة تحتوي على الصفحة الرئيسية المحسنة وملفات CSS/JS/config اللازمة لها.

## قبل الرفع
1. انسخ `index.html` إلى جذر الموقع.
2. انسخ مجلد `assets` إلى جذر الموقع.
3. اترك ملفات الفيديو والصور الحالية في أماكنها نفسها:
   - q.m4v
   - Hpt.m4v
   - Wigha.m4v
   - q1.png / r1.png / d1.png / s1.png
   - mp4.wav
4. افتح `assets/js/config.js` وعدّل:
   - whatsappNumber إلى رقم الشركة الدولي بدون + أو مسافات.
   - facebookUrl
   - tiktokUrl
   - googleMapsUrl
   - googleMapsEmbedUrl (اختياري)
5. إذا كان لديك صورة مشاركة اجتماعية حقيقية، ضعها في:
   `assets/images/og-cover.jpg`
6. بقية صفحات الموقع (`flights.html`, `hotels.html`, `booking.html`...) يجب أن تكون موجودة في جذر الموقع حتى تعمل الروابط.

## ملاحظة مهمة عن الموسيقى
المتصفحات الحديثة تمنع عادة تشغيل الصوت تلقائيًا بصوت مسموع دون تفاعل من المستخدم. الكود يحاول بدء الموسيقى بعد أول تفاعل، ويوفر زرًا ثابتًا للتحكم بها. هذا أكثر موثوقية من إجبار autoplay.

## ملاحظة الحجز
النموذج يرسل "طلب حجز" مرتبًا إلى واتساب. لا يوجد في هذه النسخة إصدار تذاكر أو تأكيد سعر تلقائي.
